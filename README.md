## 🚀 Featured Projects

### 🤖 [jhk_claude](https://github.com/JHKoder/jhk_claude)
**Claude Code 품질 측정 & 실험 분석 시스템**

토큰 효율성과 코드 품질을 정량화하고, 자동으로 분석 리포트를 생성하는 완전 자동화 시스템입니다.
- 코드 정확도, 첫 완성도, 복잡도 자동 측정
- 실험 데이터 기반의 통계 분석
- 자동화된 대시보드 리포팅

### 📡 [Monitoring](https://github.com/JHKoder/Monitoring)
**실시간 네트워크 모니터링 서비스**

조직별 외부 인터넷 및 주소 연결 상태를 실시간으로 관리하는 엔터프라이즈 모니터링 솔루션입니다.
- Spring Boot 2.7, Java 11 기반
- 실시간 연결 상태 감시
- 자동 장애 감지 및 알림
- Integration & Entity TEST, Automatic Deploy

### 🍳 [Fridge-Chef](https://github.com/Fridge-Chef/FridgeChef_BE)
**냉장고 재료 기반 레시피 추천 플랫폼**

팀 프로젝트로 냉장고 안의 재료로 만들 수 있는 레시피를 추천하고 공유하는 서비스입니다.
- 백엔드 담당 (Spring Boot, Gradle)
- 사용자 중심의 API 설계
- 팀 협업 경험
